# Instalación y Ejecución

## Requisitos

* Python 3.x
* Visual Studio Code
* Git
* GitHub

## Clonar el repositorio

```bash
git clone URL_DEL_REPOSITORIO
```

## Acceder al proyecto

```bash
cd PROYECTO_METODOS_NUMERICOS
```

## Ejecutar programas

Ejemplo:

```bash
python Unidad1/unidad1.py
```

Cada unidad contiene uno o más programas que pueden ejecutarse de forma independiente.
