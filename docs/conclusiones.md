# Conclusiones Generales

El desarrollo de este proyecto permitió aplicar de manera práctica los conocimientos adquiridos durante el curso de Métodos Numéricos, implementando diferentes algoritmos mediante el lenguaje de programación Python. La construcción de cada programa facilitó la comprensión de los procedimientos matemáticos involucrados y evidenció la importancia de la programación como herramienta para la resolución de problemas científicos y de ingeniería.

A lo largo de las distintas unidades se trabajó con conceptos fundamentales como el análisis de errores, la búsqueda de raíces de ecuaciones, la solución de sistemas de ecuaciones lineales, la integración numérica y la interpolación. Cada uno de estos métodos presentó características particulares en cuanto a precisión, velocidad de convergencia y aplicabilidad, permitiendo comparar distintas estrategias para abordar un mismo problema.

Además de los conocimientos matemáticos, el proyecto contribuyó al fortalecimiento de competencias relacionadas con el desarrollo de software, la documentación técnica y el uso de herramientas de control y organización de proyectos. La utilización de GitHub permitió estructurar adecuadamente los archivos, mantener la documentación organizada y presentar el trabajo de una manera profesional.

Finalmente, se concluye que los métodos numéricos representan una herramienta indispensable en el ámbito académico y profesional, ya que permiten obtener soluciones aproximadas con un alto nivel de precisión cuando las soluciones exactas no son viables. La implementación práctica de estos métodos contribuyó significativamente al desarrollo de habilidades analíticas y computacionales que serán de utilidad en futuros proyectos y aplicaciones profesionales.
