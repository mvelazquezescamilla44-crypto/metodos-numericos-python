# Unidad 4: Integración Numérica mediante el Método de Simpson 1/3

## Objetivo

Implementar el método de Simpson 1/3 para aproximar el valor de integrales definidas mediante técnicas numéricas.

## Fundamento Teórico

El método de Simpson 1/3 es una técnica de integración numérica que aproxima el área bajo una curva utilizando polinomios de segundo grado.

Este método ofrece una mayor precisión que otros métodos simples de integración cuando la función es continua y suave en el intervalo de integración.

## Descripción del Programa

El programa solicita:

* La función matemática.
* El límite inferior de integración.
* El límite superior de integración.
* El número de intervalos.

Posteriormente calcula el valor aproximado de la integral utilizando la regla de Simpson 1/3.

## Archivo Principal

simpson.py

## Algoritmo

1. Ingresar la función.
2. Definir los límites de integración.
3. Ingresar el número de intervalos.
4. Calcular el tamaño de paso.
5. Evaluar la función en cada punto.
6. Aplicar la fórmula de Simpson 1/3.
7. Mostrar el resultado aproximado.
