## Descripción

Este proyecto contiene la implementación de diversos métodos numéricos desarrollados en Python.

El repositorio incluye programas organizados por unidad, documentación, evidencias de ejecución y ejercicios en PDF utilizados como referencia durante el desarrollo del proyecto.

---

## Objetivo General

Aplicar métodos numéricos mediante programación en Python para resolver problemas matemáticos de aproximación, raíces, sistemas de ecuaciones, integración e interpolación.

---

## Instalación

Clonar el repositorio:

```bash
git clone URL_DEL_REPOSITORIO
```

Entrar a la carpeta:

```bash
cd PROYECTO_METODOS_NUMERICOS
```

---

## Ejecución

Cada programa se puede ejecutar de forma independiente.

Ejemplo:

```bash
python Unidad1/unidad1.py
```

Otro ejemplo:

```bash
python Unidad2/biseccion.py
```
